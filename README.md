# GDSP

Proyecto de sitio web con cuatro secciones para trabajo colaborativo en GitHub.

## Estructura del sitio

- Inicio
- Nosotros
- Servicios
- Contacto

## Flujo recomendado de trabajo

1. Crear la rama `main` como rama principal.
2. Cada integrante crea su rama desde `main`.
3. Ejemplo:
   - `feature/inicio`
   - `feature/nosotros`
   - `feature/servicios`
   - `feature/contacto`
4. Realizar commits claros y descriptivos.
5. Abrir Pull Request hacia `main`.
6. Revisar y hacer merge.

## Cómo abrir el proyecto

Abre el archivo `index.html` en el navegador o usa un servidor local.

Ejemplo con Python:

```bash
python -m http.server 8000
```

Luego visita:

```text
http://localhost:8000
```

## GitHub Pages

Para desplegar y compartir la liga:

1. Ir a `Settings` > `Pages`.
2. Seleccionar la rama `main`.
3. Guardar.
4. Copiar la liga generada por GitHub Pages.

## Proyecto base

Este repositorio incluye una landing page responsiva con diseño moderno y contenido listo para presentar.
